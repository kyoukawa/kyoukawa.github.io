连接点只有三处：触发词 / 手册路径 / 子代理指令。
框架不 import 业务代码，业务不依赖框架。

在做什么

  • 多 Agent 架构 —— 六个独立技能改造成双层路由：Router 分派，Worker 隔离执行
  • 本地优先 —— 视频转写用系统语音识别，不花钱、不排队、不限次
  • 知识沉淀 —— 阅读笔记、作文语料库，长期维护在同一套结构里

技术偏好

  • 平台 —— iOS + iSH（Alpine / musl），没有 root 也没有 node_modules
  • 依赖 —— 标准库优先，能 apk add 就不 pip install
  • 数据 —— 本地文件为权威，云端只做镜像
  • 自动化 —— 手动触发优于定时任务：定时任务会静默失败
